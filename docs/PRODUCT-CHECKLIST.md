# 一、App（H5）

## 通用框架
- 底部导航三个入口：匹配、广场、我的；页面向下滚动时导航自动收起，向上滚动或回到顶部时恢复
- 已在广场页时重按「广场」导航：平滑回到顶部并刷新当前信息流，另一个信息流的内容与浏览位置不受影响
- 全站中英双语：语言弹窗内选「中文 / English」，需点「确定」才生效，切换后整页重新加载；默认英文
- 中文模式下界面文案整体翻译；用户自己发布的内容（帖子、聊天、昵称、备注等）保持原文不被翻译
- 中文模式下学校、城市、专业、国籍、年级等资料选项显示中文名称，实际保存的仍是英文原文
- 深色模式开关：设置页与聊天页加号菜单均可切换，切换时有开启 / 关闭提示；默认浅色
- 下拉刷新：匹配页（聊天视图刷会话列表、匹配视图刷匹配状态）、广场页（刷当前信息流）、我的页（刷个人资料）；下拉超过约 70 像素松手触发，刷新动画至少停留 0.6 秒
- 我的页下拉时背景模糊随拉距逐渐消散，拉到约 140 像素背景完全清晰，松手自动弹回
- 侧滑返回手势：带返回箭头的界面（聊天、通知、帖子详情、好友面板、问卷等）从屏幕左边缘向右滑，滑过 80 像素松手即返回，不足则弹回原位
- 底部弹层（如匹配偏好）可按住顶部向下拖动关闭，拖过约 110 像素松手关闭，不足弹回
- 关键操作（退出登录、解除关系等）弹出确认卡片，含取消 / 确认双按钮，点卡片外空白可放弃；需要输入的场景弹出输入卡片
- 操作结果以轻提示浮层显示，约 3 秒自动消失
- 登录状态失效时自动清空本地数据并回到登录页，换账号登录不会看到上一账号的任何内容
- 可添加到手机主屏幕当 App 使用（PWA）：独立全屏窗口打开，自带应用图标与名称

## 启动页
- 品牌 Logo、UNIMATCHA 字标、标语「每周一次，用心匹配」与 BETA 标识
- 底部进度线加载动画
- 右上角跳过按钮，点击立即进入应用
- 约 3 秒后自动进入：已登录且资料完整进主页，未登录进登录页，资料未填完进注册资料向导
- 页面资源加载失败、或 7 秒内仍未启动时，自动刷新重试一次；再次失败不再循环刷新，转为可手动重试的失败提示

## 登录 / 注册页
- 顶部「登录 / 注册」双标签切换
- 登录：邮箱 + 密码；任一项为空拦截并提示补全；密码输入隐藏显示；登录失败弹出原因提示
- 忘记密码按钮（预留入口，暂未接入找回流程）
- 注册：邮箱 + 密码 + 确认密码；密码至少 8 位；两次密码不一致时拦截并提示
- 注册成功直接进入注册资料向导
- 页脚用户协议、隐私政策入口（点击打开对应内容页）与版权信息
- 封禁账号提示页：说明账号因违反社区规范被停用、可联系客服申诉；页面仅保留退出登录按钮，点击弹确认卡片

## 注册资料向导（新用户）
### 必填四步（每项一屏）
- 顶部显示步数「1 / 4」与进度条，每步推进 25%；第 2 步起出现「上一步」；最后一步按钮变为「继续」
- 左上角返回箭头可退回登录页
- 每步留空拦截：未填写时弹出对应提示，无法进入下一步
- 第 1 步昵称：单行输入，附说明「昵称是别人看到的名字」
- 第 2 步真实姓名：名、姓两个输入框均必填，附说明「仅对确认的伴侣可见」
- 第 3 步性别：男 / 女 / 非二元 / 其他 四选一，附说明「仅用于匹配，不公开展示」
- 第 4 步生日：日期选择器只允许 16–40 岁对应区间；超出区间提示「仅面向 16–40 岁学生」；按生日自动推算年龄，对外只展示年龄、不展示生日

### 选填资料（四步完成后展示）
- 头像上传：点击圆形区域从相册选图，上传成功即生效并提示；失败弹出原因
- 学校下拉：78 所英国大学；城市下拉：50 个城市；专业下拉：67 个专业；MBTI 下拉：16 型；国籍下拉：40 项（含「其他」）
- 下拉选项加载失败时提示「加载失败请重试」，重新打开会再次加载
- 想认识：男 / 女 / 不限 三选一，默认不限
- 学业阶段：大一新生 / 本科 / 硕士 / 博士 四选一，默认本科
- 兴趣标签：四个预设标签一键添加；自定义输入框配显式「添加」按钮（回车也可添加）；最多 8 个，重复输入自动忽略，点标签上的 × 移除
- 个人简介：最长 250 字，输入时实时字数统计
- 「完成资料」按钮：提交前再次校验昵称、真实姓名、性别、生日必填，任一缺失拦截并提示
- 保存成功进入主页，并展示恋人 / 朋友两张问卷引导卡（两份问卷均为选填）
- 已有资料的用户重进向导时，此前填写的内容自动回填

## 匹配页（主页，三个视图）
### 顶部栏（三视图共用）
- 顶部三段切换：Chat / 恋人匹配 / 朋友匹配，随时互切
- 左上按钮随视图变化：Chat 视图为加号菜单，恋人/朋友视图为匹配设置入口
- 右上通知铃铛，未读数量以粉色角标显示，点开通知面板
- 整页下拉刷新：Chat 视图刷新会话列表，恋人/朋友视图刷新匹配状态

### Chat 视图
- 会话列表分两组：临时对话（未双确认）与已确认关系；某组为空时整组隐藏
- 每行显示：头像（无头像用昵称首字母替代）、昵称、备注小标签（如已设置）、最近一条消息摘要（图片消息显示为照片、超长自动截断、无消息时提示开始对话）
- 未读消息以粉色圆点标记
- 临时会话行带剩余时间角标：按剩余小时/分钟每秒递减，不足 1 小时变红色警示，归零显示即将过期并整行置灰
- 已确认组内恋人会话固定排在朋友会话之前
- 点任意会话行进入对应聊天
- 能量退款横幅：有退款时置顶展示，文案区分两种原因——48 小时未双确认退回 N 格、本轮无可配对象退回 N 格；点横幅打开能量充值，点关闭可收起；退款到账后余额自动更新
- 空态：无任何会话时显示提示，引导先去恋人或朋友模式匹配
- 加号菜单五项：搜索会话、扫码加好友、关系网、深色模式、语言切换；点背景关闭

### 恋人视图 / 朋友视图
- 进入该模式先检查对应问卷是否完成：未完成显示引导卡（说明加一个填写问卷按钮），点按进入问卷页；点加入匹配池时同样再校验一次
- 空闲态：静止动画、模式标题（恋人为开始你的旅程；朋友为寻找新朋友，提示最多可发现 5 位同好）、加入匹配池主按钮、修改偏好入口
- 匹配中态：动画转为荧光绿播放、距下轮公布倒计时（时分秒逐秒走动，超一天带天数；公布时间以平台设置为准，默认每周五 17:00）、本轮用了增强时显示已增强徽标、离开匹配池按钮、修改偏好入口
- 匹配状态自动刷新；连续多次刷新失败时提示检查网络后重试，已有结果卡片不会被清空
- 进池成功提示已进入匹配池（增强时附带消耗格数）；离开成功提示已离开
- 已在本轮池中再点加入不会重复扣费，仅提示已在池中；带增强时提示需先离开池再以增强身份加入

### 恋人揭晓与关系
- 本周匹配卡：对方封面/头像做背景，展示头像、昵称、校园认证标记、学校与年级、共同兴趣标签（最多 6 个）
- 卡内 48 小时双确认倒计时（时分秒），提示双方需在聊天中点确认恋人；自己已确认时显示等待对方回应；归零自动刷新状态
- 进入对话按钮直达与对方的聊天
- 本周无匹配空态：提示本周无缘分、下周五再见；提供再次匹配按钮与修改偏好入口；不会自动续入下一轮，须手动再进池
- 48 小时内未双确认自动过期，增强能量按规则退回并在 Chat 视图横幅提示
- 双方确认后确立恋人关系：恋人视图整体变为情侣互动空间（纪念日、状态、日程等），空间内提供解除关系入口；加载失败可重试
- 对方资料异常时显示资料不可用卡与刷新按钮

### 朋友候选与关系
- 候选卡列表最多 5 张，标题显示候选数量
- 每卡：封面/头像、昵称、学校、简介（最多两行）、兴趣标签（最多 5 个）、状态区（48 小时倒计时 / 已是朋友标记 / 待定）、进入对话按钮、取消连接入口
- 未确认卡提示双方需在 48 小时内于聊天中点确认朋友；倒计时逐秒递减、不足时变红，归零自动刷新
- 已确认的朋友卡显示朋友标记，不再倒计时
- 朋友模式确认部分候选后仍持续接收本轮新增候选
- 本轮无朋友候选空态：提示调整偏好或再次匹配，附再次匹配按钮与修改偏好入口

### 解除关系
- 解除前弹窗二次确认：恋人版提示关系结束后双方无法再发消息；朋友版提示将不再作为朋友；确认键为红色警示样式
- 解除成功提示关系已结束/友谊已结束，界面回到可再匹配状态

### 匹配偏好弹窗
- 顶部恋人/朋友两个选项卡，两套偏好独立保存
- 恋人区：目标性别三选一（男/女/不限）；学段多选（本科/硕士/博士，可多选可全不选）
- 朋友区：目标性别三选一（男/女/不限）；兴趣优先级从自己资料的兴趣标签中挑选，最多 3 个，超选即提示；资料无兴趣时提示先去资料页添加
- 共用区：年龄区间双滑杆，可选范围 18–30 岁（默认 18–24）；最小值大于最大值时保存自动纠正；勾选不限年龄后滑杆停用、显示不限
- 共用区开关：仅限同校、同城
- 保存按钮保存当前选项卡模式的偏好，成功提示并关闭弹窗；保存中按钮置忙防连点

### 匹配设置面板（左上角入口）
- 重新作答问卷入口：进入当前模式问卷，在已有答案基础上修改
- 补充说明输入框：自由文字辅助匹配，上限 500 字
- 增强模式区（下次进池时生效）：
  - 恋人增强开关：固定消耗 3 格能量，本轮未匹配到全额退回
  - 朋友增强开关：开启后出现 1–5 档滑杆，档位即保底匹配朋友数，每保底 1 人消耗 1 格；实际匹配不足按缺口退回
  - 开启任一增强前校验能量余额，不足则提示并直接打开充值弹窗，开关不翻转
- 开着增强点加入匹配池时弹确认卡：写明本次扣几格、当前余额与退款规则；可选确认扣费进入、不用增强按普通身份进入（开关同步复位）、点背景关闭放弃本次进池
- 扣费进池成功后增强开关自动复位（按轮付费，下轮需重新开启）
- 保存按钮保存补充说明；偏好加载失败时提示，且不会用空白覆盖服务器上已有的补充说明

### 对方公开资料全屏页
- 从匹配卡、候选卡或聊天头像打开
- 封面大图、头像、昵称、校园认证标记（未认证显示未认证标签）
- 备注功能:可为对方设置备注名，显示为昵称旁小标签；留空保存即清除
- 展示真实姓名（对方公开时）、学校、年级·年龄·城市、已认识天数
- 档案格：专业 / MBTI / 星座 / 国籍，有几项显示几项
- 兴趣标签与个人简介
- 照片墙：首图大图加两张侧图，其余三列网格；显示照片总数；点击看大图
- 加载失败时提示

## 问卷页
- 两套独立问卷：恋人 50 题、朋友 25 题，作答进度与完成状态互不影响
- 注册后首次进主页弹出双卡引导：恋人/朋友问卷各一张卡，未填显示开始、已填显示对勾并变为重新作答；可点以后再说跳过，两份均非强制
- 正式作答前弹提示卡：说明问题较犀利直接、无冒犯之意、答案严格保密不公开；选我准备好了进入，选再想想留在引导页
- 页面顶部：模式标识（恋人/朋友）、进度显示（当前题号/总题数）、进度条、大题号水印
- 题面中英双语：中文态显示中文原题，英文态显示英文题面（缺英文回退中文）
- 题型支持单选、多选、五档量表、文字填空；当前题库全部为五档量表且每题必答
- 五档量表选项：非常同意 / 同意 / 中立 / 不同意 / 非常不同意
- 文字题为多行输入框，切题时已输入内容自动保留
- 底部上一题/下一题按钮：第一题隐藏上一题，最后一题的下一题变为提交
- 题目导航：右上角网格按钮弹出底部弹层，所有题号排成网格，绿色为已答、描边为未答、圈线标当前题，点任意题号直接跳转；弹层带图例说明
- 断点续答：中途退出再进不丢已答内容，自动定位到第一道未答题
- 提交前校验：存在未答的必答题时自动跳到该题并提示补答
- 提交中按钮禁用，防止重复提交
- 提交成功提示已答题数，自动回到主页并切换到刚完成问卷的匹配视图
- 重新作答：从匹配设置进入，在保留原答案的基础上修改后重新提交
- 问卷加载失败时提示

## 聊天会话页

### 会话列表与入口
- 会话按「待确认的匹配对话」与「已确认关系」两组分列；已确认组内恋人会话固定排在朋友会话之前
- 每行显示对方头像（无头像显示昵称首字母）、昵称、备注小标签（如已设备注）、最后一条消息预览（超 28 字截断，图片消息显示为「图片」，没有消息时提示开始对话）
- 有未读消息的会话行显示粉色圆点
- 待确认对话行带剩余时间角标：按小时倒数、不足 1 小时改按分钟显示并变红提醒、每秒实时递减；归零后角标变灰、整行变淡，随后该会话从列表消失
- 待确认对话的确认期为匹配后 48 小时，超时未双方确认即过期，双方不能再发消息
- 已解除、已过期、已拒绝的会话不出现在列表中
- 有能量退款时列表顶部出现退款横幅（区分「48 小时未确认退款」与「本轮无人可配退款」，显示退回格数），点横幅打开能量充值，可点关闭收起
- 空态：图标加提示「还没有对话」，说明在恋人或朋友模式匹配成功后对话会出现在这里
- 列表加载失败弹出提示

### 顶部信息与关系操作
- 顶部显示对方头像、昵称、学校；点头像查看对方公开资料
- 待确认对话在头部显示确认按钮，按匹配模式自动显示「确认为恋人」或「确认为朋友」
- 点确认后按钮变为不可点的「等待对方确认」；若对方已先确认，关系当场成立并提示已连接
- 头部常驻「解除关系」入口，待确认与已确认对话都有
- 解除前弹出二次确认弹窗，说明对方会收到通知、双方都无法再发消息；确认后提示已解除，对话关闭并从列表消失
- 确认与解除按钮均防连点，处理中自动置灰

### 收发消息
- 文字消息：单条上限 2000 字
- 图片消息:点输入框旁加号选一张图片，先在输入区上方出现缩略图预览，可点角标移除重选；可附带文字，发送时先发图片、文字作为说明单独跟发
- 自己发出的消息立即上屏并滚动到底部
- 对方新消息自动出现，无需手动刷新（最长约 5 秒延迟）；停留在底部附近时自动跟随滚动
- 每条消息显示发送时间（刚刚、N 分钟前、N 小时前等相对时间，随界面语言切换中英文）
- 进入对话自动定位到最新消息；滚动到顶部自动展开更早的消息，每次 30 条
- 已读回执：自己的消息被对方看过后，时间旁追加「已读」标记并自动更新；打开对话即为对方消息标记已读
- 发送失败弹出提示；若因关系已结束被拒，明确提示无法再发送并立即锁定输入区

### 对话内对方头像菜单
- 点消息气泡旁的对方头像弹出小菜单，点其他区域收起
- 拍一拍：仅已确认对话可用；发出一条居中灰字的系统提示「某某拍了拍某某＋后缀」，双方可见，并把该会话顶到列表前面
- 拍一拍后缀在设置里自定义（上限 40 字，如「的头」），设置的是别人拍自己时显示的文案
- 设置备注：给对方起备注名，上限 30 字，留空保存即清除；备注显示在会话列表昵称旁及搜索结果中
- 聊天背景：仅已确认对话可用；选一张图片作为该对话专属壁纸，铺在消息区后方，每个对话可各设一张，设置成功有提示

### 图片查看与结束态
- 点对话中的任意图片全屏查看（黑底大图），点任意处关闭
- 关系已解除或已过期的对话：输入框、发送键、发图键全部禁用，输入框提示关系已结束，消息区上方显示「此连接已结束，无法再发送消息」；解除瞬间若仍停留在对话内可回看历史

## 加好友 / 关系网

### 入口
- 聊天首页左上角加号弹出快捷菜单：搜索会话、扫码添加、关系网，另含深色模式与语言切换两个快捷项

### 我的连接码
- 「我的二维码 / 扫一扫」两段式切换
- 我的二维码：展示我的专属二维码，下方显示连接码明文（CL 开头加 8 位字母数字），点一下整段选中便于复制

- 获取失败时码位显示不可用并弹出提示

- 与已解除的朋友重新扫码，朋友关系即恢复
- 不能添加自己；连接码无效、对方账号不可用均有明确失败提示
- 处理中防重复提交，连续扫到或连点添加不会重复发起

### 关系网图谱

- 我到每人的连线粗细代表亲密度，由聊天数量、最近聊天时间、广场帖子间的点赞评论互动综合计算
- 恋人连线为粉色，朋友连线为黑色

- 图下方常驻说明：线越粗越亲密，点头像开聊
- 空态提示还没有连接并引导去加好友；有加载中与加载失败提示

### 搜索会话
- 在已有对话中搜索，不用于结识新人；进入即列出全部会话并自动聚焦输入框
- 边输入边出结果，可按昵称、备注、学校、最后一条消息内容匹配
- 结果行显示头像、备注名（无备注显示昵称），副行显示最后一条消息或学校名

- 无结果时提示未找到会话

## 广场页（推荐 / 校园墙双页）

### 页面结构与切换
- 顶栏两个页签：推荐、校园墙，荧光绿下划线滑动指示当前页
- 双页左右横滑跟手切换，滑动幅度足够即翻页、不足自动弹回，越界方向有橡皮筋阻尼
- 两页滚动位置各自独立记忆，切回即恢复；离开广场再进入则回到顶部重新开始
- 进入广场时两页内容同时预载，切页不重新加载，保留浏览进度
- 重按底部导航的广场键：平滑回到顶部并只刷新当前页，另一页内容与位置不动
- 下拉刷新当前信息流：圆形指示器跟手下降并旋转，过阈值变绿、松手转圈刷新，动画至少展示 0.6 秒后收回

### 搜索
- 右上角搜索图标展开搜索条，自动聚焦输入框
- 输入后点「搜索」按钮或按回车执行；有关键词时出现清除按钮
- 搜索只筛当前页信息流；搜索结果中不插广告
- 收起搜索条不清空结果，搜索图标变荧光绿提示当前处于筛选中
- 点清除按钮清空关键词并恢复完整信息流
- 点搜索区域以外自动收起搜索条，点信息流不收起
- 切换推荐/校园墙页签自动清空搜索词与结果

### 信息流与卡片
- 推荐流：双列瀑布流图文混排，卡片垂直间距恒定，图片卡高度随原图比例（有上下限收敛），布局随图片加载自动重排
- 纯文字小卡：竖版固定比例、按帖子固定的低饱和浅色底、手写风字体，正文最多显示 5 行
- 校园墙帖：整行竖排大卡，含头像、昵称、发布时间、学校标签、横幅大图、标题、正文（最多 3 行）、点赞与评论数；出现在推荐流时仍保持此样式
- 官方帖（学生会 / 官方团队 / 赞助商）：整行大图卡，左上官方或 Sponsored 徽标、右上学校标签；无图时退为整行文字卡
- 每张卡片显示作者学校标签；匿名帖学校只取帖子自身标注，绝不回溯作者资料
- 匿名帖显示系统分配的趣味化名与中性头像占位，不显示真实昵称与头像
- 情侣共同发布的帖子，作者位显示两人头像叠放
- 发布时间为相对时间：1 分钟内「刚刚」、1 小时内按分钟、24 小时内按小时、7 天内按天，更早显示日期
- 校园墙未绑定学校时显示引导：提示先在资料里补学校，附「完善资料」按钮直达我的页

### 发帖
- 圆形发帖悬浮按钮可拖动：松手后左右就近吸边，位置持久记住、下次进入仍在原位；拖动期间不触发横滑切页，拖完的这次松手不误触发帖
- 发帖去向由打开时所在页决定（推荐或校园墙），弹窗内只读提示、不可手动切换
- 在校园墙页发帖前若未绑定学校，先提示补学校并直接跳到我的页
- 标题：选填，最多 100 字
- 正文：必填，最多 2000 字；为空提交时提示先写点内容
- 图片：最多 4 张，可逐张删除；满 4 张后隐藏添加入口
- 匿名开关：开启后以化名发布，学校标签照常显示
- 发布中按钮置灰防重复提交；发布成功后自动跳到对应页并刷新
- 取消按钮直接关闭发帖弹窗

### 校园墙投票帖
- 「发起投票」开关仅校园墙发帖时出现，开关下注明审核通过后展示
- 开启投票后去向强制为校园墙；关掉开关则还原为打开发帖时的去向
- 投票选项 2 至 6 个，每个最多 50 字；默认 2 个输入框，可逐个添加，超过 6 个提示已达上限
- 有效选项不足 2 个无法提交，提示至少需要 2 个选项
- 提交后进入审核，成功提示审核通过后展示；待审期间仅作者可见并带「审核中」标记，被驳回带「已驳回」标记，审核结果会通知作者
- 审核通过后所有人可投票：点选项即投，已投可点其他选项改票
- 选项行显示占比条与百分比，自己的选择高亮；底部显示总票数，已投后提示可点选改票

### 活动帖与购票
- 活动帖卡片带活动标记行：开始时间、地点、票价（免费活动显示免费），售罄显示已售罄
- 详情页活动区块：起止时间、地点、票价、剩余票数、已售数量、主办学校
- 购票按钮按状态变化：可购时显示「购票 + 价格」；售罄、活动已结束、已停售时按钮置灰并显示对应文案
- 点购票弹出确认弹窗，说明测试期为模拟支付、票券即时进入「我的票夹」，确认后出票
- 每人每个活动限购 2 张，超出提示已达限购
- 售罄后不超卖，购票失败提示售罄
- 购票成功提示票码并存入「我的票夹」（我的页入口），详情页余票与已售数即时刷新

### 广告帖
- 仅推荐流展示；校园墙与搜索结果不插广告，未绑定学校时不展示广告

- 广告加载失败静默隐藏，不影响正常信息流

### 帖子详情
- 从任意卡片点开全屏详情，左上返回键关闭
- 单图整幅展示；多图横滑轮播，带左右翻页箭头与底部进度条指示，滑到首尾不越界
- 作者区：头像（情侣帖双头像叠放）、昵称或化名、官方或 Sponsored 徽标、学校标签、发布时间

- 互动行：点赞按钮与评论数按钮；点评论数直达底部评论输入框并聚焦

- 详情内的点赞、评论数变化返回列表后同步显示，无需刷新
- 加载失败弹出提示

- 评论按楼层分组：父楼在上、回复缩进跟在楼内，回复的回复也归入同一楼
- 每条评论显示头像、昵称、时间、内容与「回复」按钮
- 帖子作者自己的评论带「作者」标记；匿名帖同样能标记作者且不暴露真实身份
- 点回复出现「正在回复某某」提示条，可点取消；取消后已输入草稿保留，将作为普通评论发出
- 评论输入框在页面底部，圆形发送键；单条评论最多 500 字
- 发送成功后清空输入框并刷新评论列表，失败弹出原因提示
- 无评论时显示空态提示，邀请发布第一条评论
- 评论区标题显示评论总数（含回复）

### 点赞
- 卡片与详情页均可点赞，再点取消；心形图标点亮为粉色实心并即时增减计数
- 同一帖在两页各有卡片时点赞状态同步
- 点赞失败弹出提示

- 信息流为空：显示空态图标与提示，邀请成为第一个发帖的人
- 加载失败：显示失败提示与「重试」按钮，点重试重新加载
- 校园墙未绑学校：显示补学校引导与「完善资料」按钮

## 情侣空间（恋人关系后）

- 纪念日与心愿打卡均可一次选多张照片依次上传
- 部分失败时如实提示成功张数与失败张数；全部失败提示上传失败

- 确认后关系解除，提示成功并返回匹配页

## 我的页
### 头部展示
- 顶部背景为编辑资料中设置的封面图，未设置显示灰色占位
- 背景上覆盖模糊层，头像、昵称、学校胶囊居中显示其上

### 能量余额条

四种角色：平台超管（SUPER）、平台团队（TEAM）、学生会（STUDENT_UNION）、商家（SPONSOR）。学生会只能看到本校范围，商家只能看到自己的投放。

- 新建赞助商弹窗：组织名、账号名称、登录邮箱、初始密码（至少 8 位）必填，联系人、联系电话选填；提示交付商家后建议其自行改密
- 停用/启用带确认弹窗：停用后无法登录与投放，进行中的广告不受影响

### 个人账户页（商家导航入口，任意角色可用）
- 账户信息只读卡：组织名（商家）、登录邮箱、角色、所属学校、联系人、联系电话、来源（平台直签/学生会自拉）；提示组织与联系方式由平台或学生会维护
- 修改显示名称：非空校验，保存后侧栏立即更新
- 修改密码：新密码至少 8 位，需再次输入确认，两次不一致拦截；成功后提示下次登录用新密码

## 广告管理
（同一入口按角色显示不同版本）

### 广告列表
- 商家版「我的广告」：列为标题、计价、投放学校数、档期、报价/预算、消耗、状态、详情；右上角「新建广告」；空态「还没有广告」并附新建按钮
- 学生会版「广告审核」：两个页签——「待我审核」（带待审数量角标）与「本校广告」（只读，含商家、来源、消耗列）
- 平台版：状态筛选（草稿/学生会待审/平台待审/已驳回/待付款/待开始/投放中/已暂停/已下架/已完成 共 10 态）、学校筛选、「待审核」快捷筛选按钮（带数量）；从总览待办点入自动套用待审筛选
- 各版每页 20 条翻页；点行进详情
- 来源统一标注：平台直签 或 某校·自拉

### 创建 / 编辑广告（商家专属；仅草稿或已驳回状态可编辑）
- 素材区：标题必填（最多 60 字）、文案必填、图片地址至少 1 条（可增删多条）、落地链接选填（留空则点击卡片仅展示详情）
- 计价模式三选一：按天包断（按天按校固定价，档期内包断展示）、CPM（每 1000 次曝光计费，预算即封顶）、CPC（按每次点击计费，预算即封顶）
- 投放学校多选；包断模式下每校旁显示日单价，未配置价的学校显示「待核价」；自拉商家学校锁定为本校且不可改
- 档期：开始/结束日期必填，起止均含当天计天数，结束早于开始拦截
- CPM/CPC 必须填写预算（元），消耗达到预算自动停止投放
- 右侧实时报价：包断=逐校「日价 × 天数」明细加总；有学校待核价时提示「提交后以平台核价为准」；CPM/CPC 显示预算封顶金额与各校单价
- 两个提交按钮：提交审核 / 存草稿；提示提交后计价按平台快照锁定、审核期间不可编辑

### 广告详情与生命周期操作
- 顶部显示标题、状态徽章、计价模式、档期、商家、来源
- 操作栏按角色与状态出现：商家（本人广告）——编辑与提交审核（草稿/已驳回）、暂停（投放中）、恢复（已暂停）；学生会——通过/驳回（学生会待审）；平台——通过/驳回（平台待审）、确认收款（待付款）、暂停/恢复、强制下架（待开始/投放中/已暂停）、恢复上架（已下架）
- 每个操作均有确认弹窗；驳回原因必填、审核通过备注选填、确认收款备注选填（确认线下款项到账后进入排期、到起始日自动投放）、强制下架原因必填（立即停止展示，团队可解除）
- 自拉赞助广告在操作栏与审核弹窗显示「分成按本校自拉档计算」提示
- 数据卡：曝光、点击、CTR、消耗四统计 + 每日曝光/点击趋势图；未投放显示空态
- 素材卡：图片横滑预览、文案全文、落地链接（新窗口打开）
- 金额卡：报价（包断）或预算（CPM/CPC）+ 已消耗；投放学校卡逐校列出（包断附每校价格）
- 流转记录时间线：创建、审核备注、驳回原因、确认收款、强制下架、投放完成、分成已入账，各带时间与备注

## 内容审核

### 帖子管理
- 筛选：板块（全部/推荐流/校园墙）、学校名（仅平台可用）、状态（全部/展示中/已隐藏）、关键词搜索（标题/内容），输入后自动刷新；每页 20 条翻页
- 列表列：内容（标题+摘要+图片张数）、作者（类型徽章：用户/学生会/团队/商家，附名字与匿名徽章）、学校（无学校标「跨校」）、板块、互动（赞数·评论数）、举报数、状态（展示中/已隐藏，附隐藏原因）、时间、操作
- 「查看」弹窗：帖子全文、图片九宫格、赞助标记、板块与学校、互动与举报数、发布时间、下架原因与时间

### 投票审核

- 列表列：投票内容、选项列表（各选项当前票数）、学校（平台侧对有学生会的学校标「本校有学生会」）、作者（匿名帖显示匿名徽章）、提交时间、状态（已驳回附驳回理由）
- 待审核投票可「通过」（确认弹窗，通过后对用户可见）或「驳回」（理由选填、记入审核备注，驳回后不展示给用户）

### 用户反馈（仅平台）
- 状态筛选：全部 / 待处理 / 已处理；每页 20 条翻页
- 列表列：分类（功能问题/举报用户/不当内容/其他）、内容摘要（可点「查看」弹窗看全文与提交用户、联系方式、时间）、联系方式、提交用户（昵称+邮箱）、状态、时间
- 待处理反馈可一键「标记已处理」

## 系统设置（仅超管）
- 广告计价默认值：包断日价（元/天·校）、CPM 单价（元/千次曝光）、CPC 单价（元/次点击）三项均必填且须大于 0
- 说明文案：学校未配置覆盖价时生效；已提交审核的订单按提交时快照计价，此处改价不影响已提交订单
- 系统配置列表：逐项显示配置名与最近更新时间，每项配置内容可直接编辑并单独保存；保存前做格式校验，格式不合法拦截并提示
- 无配置项时显示空态，说明配置由业务模块首次写入后出现
