# App（H5）功能清单

## 通用

- 底部导航（匹配 / 广场 / 我的）
- 中英双语
- 深色模式
- 下拉刷新
- 右滑返回手势
- 添加到手机主屏幕（PWA）

## 启动页

- 启动动画
- 跳过按钮
- 加载失败自动重试

## 登录 / 注册

- 邮箱登录
- 邮箱注册
- 忘记密码（预留）
- 用户协议 / 隐私政策入口
- 封禁账号提示页

## 注册资料向导

- 分步必填：昵称、真实姓名、性别、生日
- 头像上传
- 学校 / 城市 / 专业 / 国籍 / 年级 / MBTI 选择
- 想认识的性别
- 学业阶段
- 兴趣标签
- 个人简介
- 问卷引导

## 匹配页 — Chat 视图

- 会话列表（临时 / 已确认分组）
- 未读标记
- 临时会话倒计时
- 能量退款横幅
- 会话搜索
- 加号菜单（搜索 / 扫码 / 关系网 / 深色模式 / 语言）

## 匹配页 — 恋人 / 朋友视图

- 问卷未完成引导
- 加入 / 离开匹配池
- 匹配中动画
- 公布倒计时
- 匹配偏好设置
- 增强匹配（能量付费）
- 匹配揭晓卡
- 双方确认机制（48 小时时限）
- 朋友候选列表（最多 5 位）
- 关系卡
- 解除关系
- 补充说明
- 对方公开资料页
- 备注名

## 问卷

- 恋人卷 / 朋友卷
- 单选 / 多选 / 量表 / 文字题型
- 题目导航跳题
- 断点续答
- 双语题面
- 提交与重新作答

## 聊天会话

- 文字消息
- 图片消息
- 历史消息加载
- 新消息自动更新
- 已读回执
- 拍一拍
- 聊天壁纸
- 查看对方资料
- 确认关系 / 解除关系
- 图片全屏查看
- 关系结束后锁定输入

## 加好友 / 关系网

- 我的连接码（二维码）
- 扫码加好友
- 手输连接码
- 关系网图谱
- 好友搜索

## 广场

- 推荐流（瀑布流）
- 校园墙
- 双页横滑切换
- 发帖（图文 / 匿名）
- 投票帖
- 活动帖与购票
- 官方帖 / 广告帖展示
- 帖子详情
- 点赞 / 评论 / 回复
- 帖子搜索
- 发帖悬浮按钮

## 情侣空间

- 情侣封面
- 说 100 次我爱你
- 今日状态
- 今天想吃
- 共同日程
- 纪念日
- 心愿单打卡
- 礼物罐
- 关系里程碑时间线
- 结束关系

## 我的页

- 头像 / 封面 / 学校展示
- 学生认证入口
- 能量余额
- 我的票夹（二维码门票）
- 编辑资料入口
- 联系我们
- 设置入口

## 编辑资料

- 头像 / 封面
- 昵称 / 真实姓名 / 性别 / 生日
- 学校 / 城市 / 专业 / MBTI / 国籍 / 年级
- 兴趣标签
- 简介 / 主页文案
- 照片墙
- 礼物罐

## 学生认证

- 学生证上传
- 校邮箱验证码
- 提交审核与状态展示

## 能量充值

- 余额与流水
- 套餐选择
- 支付方式选择
- 确认支付
- 未匹配 / 过期自动退还

## 通知

- 通知列表（按日分组）
- 未读角标
- 通知详情与已读
- 类型：匹配结果、匹配过期、关系确立、关系解除、新朋友、广场互动、能量退还、投票审核、情侣里程碑、系统通知

## 设置

- 修改密码
- 语言切换
- 深色模式
- 推送开关
- 拍一拍后缀
- 隐私开关（公开资料 / 在线状态 / 公开动态）
- 帮助中心 / 安全提示 / 用户协议 / 隐私政策
- 报告问题
- 退出登录
