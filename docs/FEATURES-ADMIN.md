# 管理后台功能清单（admin.unimatcha.ai）

角色：平台超管 / 平台团队 / 学生会 / 商家。学生会限本校范围，商家限自己的投放。

## 登录页

- 邮箱密码登录
- 角色说明卡

## 总览 Dashboard

- 平台版：统计卡、待办提醒、消耗趋势图、快捷入口
- 学生会版：本校统计、最近入账明细
- 商家版：投放统计、曝光点击趋势图

## 用户管理

- 用户列表（搜索 / 筛选 / 分页）
- 封禁 / 解封
- 重置匹配状态
- 学生认证审核
- 用户详情页

## 学校管理

- 学校列表
- 新建学校
- 分成配置
- 广告计价覆盖
- 银行账户管理

## 账号管理

- 学生会账号
- 商家账号
- 管理员账号
- 学生会自拉赞助商
- 个人账户（改名 / 改密码）

## 广告管理

- 广告列表（按角色范围）
- 创建 / 编辑广告（包断 / CPM / CPC）
- 多校投放与实时报价
- 学生会初审 / 平台复审
- 确认收款
- 暂停 / 恢复 / 强制下架
- 数据统计与趋势图
- 流转记录时间线

## 内容审核

- 帖子管理（查看 / 下架 / 恢复）
- 举报队列
- 投票审核
- 用户反馈处理

## 活动管理

- 活动列表与状态管理
- 发布活动（同步生成广场帖）
- 购票名单
- 入场核销

## 财务

- 提现审核
- 赞助发放
- 分校收入报表

## 收益提现（学生会）

- 余额统计
- 绑定银行卡
- 申请提现
- 提现记录与收支明细

## 官网提交

- 合作申请处理
- 一键开通账号
- 候补名单

## 官方发帖

- 板块与学校选择
- 图文发布
- 赞助内容标记

## 问卷管理

- 版本列表与发布
- 题目管理（增删 / 启停）

## 匹配管理

- 匹配计划配置
- 手动触发匹配
- 任务列表与重试

## 系统设置

- 广告默认计价
- 系统配置编辑
