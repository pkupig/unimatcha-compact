# Work-package ownership — Unimatcha iOS migration

`$APP` = `/Users/aimi/Downloads/unimatcha-compact/apps/ios/Unimatcha`. `$IOS` = `/Users/aimi/Downloads/unimatcha-compact/apps/ios`. `$H5PUB` = `/Users/aimi/Downloads/unimatcha-compact/apps/h5/public`. `$MAPS` = `/private/tmp/claude-501/-Users-aimi-Downloads-unimatcha-compact/8b05a921-d056-47e7-8007-3e616ffc8775/scratchpad/ios-migration/maps`. Read `PLAN.md` (same directory as this file) first — sections A.2.6 (overlay ids), B (foundation signatures) and B.7 (domain store contracts) are the binding contracts for anything shared between packages.

Global rules for every package:
1. Touch **only** the files listed under your package (create/edit/delete). Never edit another package's file; if you need something from it, code against the signature in PLAN.md §B/§B.7 and, if it is missing, report it in your result instead of adding it elsewhere. Legacy files are already gone after WP-01 (see §A.1 "Legacy-file strategy"); consult them with `git show HEAD:apps/ios/Unimatcha/<path>`.
2. Swift 5 mode, iOS 16, SwiftUI + `ObservableObject`. No SPM/CocoaPods. No `@Observable`, no `Observation`, no strict-concurrency-only APIs.
3. English is the source language of every string; obtain zh via `L10n.t("<exact H5 English string>")` for dictionary keys, `L10n.pick(en, zh)` for composed strings **and for your package's English-only strings** (use the zh suggested in your map; do not add them to the shared dictionary); user content is never translated; metadata values stay English (`L10n.metaLabel` for display only).
4. Colours only via `Theme.C.*`; radii via `Theme.R.*`; fonts via `Theme.font/mono`; icons via `Theme.Icon.sf(...)`. No literal hex outside `Theme.swift` (exception: alias pastel table in `Alias.swift`).
5. Only load `http(s)` and `data:image/*` URLs into images (`RemoteImage` enforces it).
6. Every store/VM that caches per-user data subscribes to `Notification.Name.sessionDidReset` and clears itself (and stops its timers).
7. Before finishing: run `$IOS/scripts/typecheck.sh` (full tree). Because WP-01 removes all legacy files, the full tree must stay green at every tier; if it fails only in files you do not own, rerun with `--only` filters covering foundation dirs + your dirs and report both outcomes (this should be rare).
8. Line budget ≤ ~2500 Swift lines per package (estimates below). Prefer splitting views into the files listed rather than one giant file.
9. Do not commit. Do not touch `CLAUDE.md`, `project.yml`, `Info.plist` unless you own them (WP-16).
10. Overlay ids: use exactly the strings in PLAN §A.2.6. Present your own overlays directly; open anything from another package only through `AppActions`.
11. Fixtures: ship `$APP/Resources/Fixtures/<your prefix>-*.json` + a `#if DEBUG enum <Domain>Fixtures { static func verify() throws }` file (PLAN §H.4). Prefixes are given per package below.

Dependency tiers (a package may start when every package it depends on has reported green):
